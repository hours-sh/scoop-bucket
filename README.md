# hours Scoop bucket

Scoop manifest for the [hours](https://hours.sh) command line interface.

`bucket/hours.json` is generated by `cli-release.yaml` in
[248-sh/hours](https://github.com/248-sh/hours) on every release. Do not edit
this repository by hand.

## Install

```powershell
scoop bucket add hours-sh https://github.com/hours-sh/scoop-bucket
scoop install hours-sh/hours
hours --version
```
